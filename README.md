# ML-Toolkit

Проект, посвящённый самостоятельной реализации алгоритмов машинного обучения на Python с использованием NumPy.

Основная цель проекта — изучить внутреннее устройство ML-алгоритмов, самостоятельно реализовать их основные механизмы и разобраться в принципах их работы без использования высокоуровневых инструментов машинного обучения.

## Структура проекта

### Основные файлы и директории

- **`MLP.py`** — модуль, реализующий инструмент для создания и настройки полносвязных нейронных сетей (Multilayer Perceptron). Пользователь может самостоятельно конструировать сети различной архитектуры, задавая количество слоёв, число нейронов и функцию активации для каждого слоя. При этом определение необходимых размерностей и инициализация матриц весов выполняются автоматически.
- **`requirements.txt`** — список зависимостей, необходимых для работы основного модуля `MLP.py`.
- **`showcase/`** — законченные реализации алгоритмов и демонстрационные ноутбуки (Jupyter Notebook), в которых описывается устройство реализаций и проверяется их работоспособность.
- **`Experiments/`** — экспериментальные реализации различных ML-алгоритмов и отдельные исследования. Некоторые из них находятся в процессе разработки.

## Реализованные алгоритмы

### Multi-Layer Perceptron (MLP)

Собственная реализация полносвязной нейронной сети с использованием NumPy.

Основной особенностью реализации является гибкая настройка архитектуры сети через простой программный интерфейс, позволяющий пользователю самостоятельно определять структуру модели без необходимости вручную задавать размерности каждого слоя.

**Основные возможности:**

- Настройка архитектуры сети с произвольным количеством слоёв.
- Выбор количества нейронов и функции активации для каждого слоя.
- Автоматическое определение количества входных признаков.
- Автоматическое формирование и инициализация матриц весов.
- Реализация прямого (Forward Propagation) и обратного (Backpropagation) распространения ошибки.
- Поддержка функций активации:
  - Identity
  - Sigmoid
  - ReLU
- Поддержка функций потерь:
  - Mean Squared Error (MSE)
  - Cross-Entropy
- Обучение с использованием градиентного спуска.

### MLP Showcase: сравнение собственной реализации с PyTorch

В директории `showcase/` находится демонстрационный ноутбук, в котором рассматривается работа собственной реализации MLP и проводится её сравнение с аналогичной моделью, созданной средствами PyTorch.

В рамках демонстрации:

- Создаётся и настраивается архитектура собственной нейронной сети.
- Проводится обучение на наборе данных MNIST.
- Реализуется аналогичная архитектура с использованием PyTorch.
- Сравниваются кривые обучения и значения функции потерь.
- Оценивается качество классификации.

Для эксперимента используется следующая архитектура полносвязной сети:

```text
Input Layer:       784 neurons
Hidden Layer 1:    512 neurons (ReLU)
Hidden Layer 2:    256 neurons (ReLU)
Output Layer:       10 neurons (Identity)
```

Обе модели используют функцию потерь Cross-Entropy и градиентный спуск.

[Перейти к демонстрационному ноутбуку](showcase/mlp_implementation_vs_pytorch.ipynb).

## Данные

Для демонстрации работы MLP использовался набор данных MNIST в CSV-формате, взятый с Kaggle:

[MNIST in CSV — Kaggle](https://www.kaggle.com/datasets/oddrationale/mnist-in-csv/data)

Используемые файлы (`mnist_train.csv` и `mnist_test.csv`) не включены в репозиторий. Для воспроизведения эксперимента их необходимо скачать и разместить в директории `datasets/` в корне проекта.

## Экспериментальные реализации

В директории `Experiments/` находятся другие реализации алгоритмов машинного обучения и связанные с ними исследования.

Среди них:
- Logistic Regression;
- Support Vector Machine (SVM);
- Model Selection.

Данные реализации находятся на разных этапах разработки и пока не имеют такого же уровня завершённости, документации и проверки, как MLP.
